<Callout title="一个密钥，畅用多个 AI 模型" type="info">
无需管理多个订阅账号。完成注册、充值／兑换并创建 API Key 后，即可把 Claude Code、Codex、Cursor 等常用工具接到 AlphaIO。
</Callout>

## 建议路径

按下面四步走完，即可完成第一次成功请求。可选步骤按需阅读。

<Steps>
<Step>

### 账号管理

使用邮箱、GitHub 或 Google 完成 [注册](/docs/account/register) 与 [登录](/docs/account/login)，进入控制台。

</Step>
<Step>

### 充值 / 兑换

通过 [充值](/docs/billing/topup) 或 [兑换](/docs/billing/redeem) 获取额度，并创建匹配目标模型分组的 API Key。

</Step>
<Step>

### 工具配置

用 [CC Switch](/docs/tools/cc-switch) 统一路由，或按客户端单独配置 [Claude Code](/docs/tools/claude-code)、[Codex](/docs/tools/codex)、[Cursor](/docs/tools/cursor) 等。

</Step>
<Step>

### 能力拓展（可选）

安装 [Agent 技能](/docs/ai/agent-skills) 在 Codex 对话中生图，或打开 [图片生成](/docs/image-generation) 使用网页工作室。遇到问题见 [常见问题](/docs/faq)。

</Step>
</Steps>
