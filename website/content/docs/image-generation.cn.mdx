在 [图片生成页面](https://ai.alphaio.vip/image-studio)，配置好图像服务后即可生成或编辑图片：**配置供应商 → 填写提示词 → 选择模型与参数 → 生成 → 下载**。

使用 AlphaIO 时，请先完成 [注册账号](/docs/register)，按 [充值或兑换](/docs/purchase) 的说明准备 API Key 和可用额度。也可以接入其他兼容图像接口的供应商，使用其提供的地址、Key 和模型。

## 首次使用：配置供应商

1. 打开图片生成页面，点击右上角 **供应商配置**。
2. 在「图像服务设置」中点击 **新增供应商**，填写以下内容。

| 字段 | 如何填写 |
| --- | --- |
| 名称 | 便于识别的名称，例如 `AlphaIO`。 |
| Base URL | AlphaIO 填 `https://ai.alphaio.vip/v1`；其他服务填写其提供的公开 HTTPS API 根地址。不要填写网站首页或完整的图片生成接口路径。 |
| API Key | 对应供应商的完整 API Key。 |
| 模型 | 点击模型标签，至少选中一个。列表里没有时，在「添加模型名称」输入准确的模型 ID，再点击 **添加**。 |

填完后点击 **保存**，该供应商会自动成为「使用中」。关闭设置窗口，回到生成页面。

模型可以多选，选中的模型才会出现在生成页面的「模型」下拉框中。页面列出的模型名称仅供选择，是否可用取决于供应商和当前 Key 的权限；保存配置不会验证接口连通性。

以后右上角会显示当前供应商名称，点击它即可重新打开设置。点击列表中的供应商可切换服务，也可以通过 **编辑** 修改地址、Key 和模型。

供应商配置保存在当前浏览器中，换设备、换浏览器或清除站点数据后需要重新配置。生成时，本站使用所填 Key 转发请求到对应供应商；每次生成或编辑都会消耗该供应商的额度。

## 用文字生成图片

1. 在 **提示词** 中描述主体、场景、风格、构图和需要保留的文字，最多 4000 个字符。
2. 保持 **参考图** 区域为空，并在 **模型** 中选择已配置的模型。
3. 第一次使用可先保留页面默认的尺寸和质量，数量设为 `1`、格式设为 `png`、背景设为「自动」。
4. 点击 **生成图片**。按钮显示「生成中」时等待结果，完成后图片会出现在预览区。

例如：

> 一只戴贝雷帽的小水獭坐在木桌前，窗外是雨天，室内暖色灯光，水彩插画，主体居中，背景简洁，不要文字。

需要补充风格时，点击 **提示词助手**，在画质、画风、构图、光影、色彩、材质分类中选择标签。标签会把对应的英文描述追加到提示词中，追加后可以继续手动修改。

## 用参考图编辑图片

1. 在 **参考图** 中点击 **上传** 选择本地图片，或先复制图片，再点击 **剪切板**。也可以点击 **历史记录**，在弹窗中勾选一张或多张已生成图片，确认后追加到参考图。
2. 确认出现参考图缩略图，然后填写修改要求，说明哪些内容要改、哪些需要保留。
3. 选择支持图生图的模型和输出参数，点击 **编辑图片**。

例如：

> 保留小水獭的外形、贝雷帽和原有构图，把窗外改成下雪的夜晚，室内仍然保持暖色灯光和水彩风格。

参考图支持 **PNG、JPEG、WebP**，单张不超过 **10MB**，最多添加 **10 张参考图**，暂不支持蒙版。多张参考图会一起发送给所选图像服务，具体支持能力以供应商和模型为准。

添加参考图后，按钮会自动从「生成图片」变为「编辑图片」，无需切换模式。点击参考图右上角的移除按钮可逐张移除，全部移除后恢复文生图。参考图会保留到手动移除或离开页面，下次生成前请确认是否仍要使用它。

## 参数怎么选

| 参数 | 使用说明 |
| --- | --- |
| 尺寸 | `auto` 交由图像服务决定；也可选择方图、横图或竖图尺寸。可选尺寸随模型变化，以当前下拉框为准。 |
| 质量 | 可选 `auto`、`low`、`medium`、`high`；部分模型还会显示 `xhigh`、`max`，需供应商支持。 |
| 数量 | 每次填写 `1`～`4` 的整数；先生成 1 张确认效果，再按需增加。 |
| 格式 | 可选 `png`、`jpeg`、`webp`。需要透明背景时使用 PNG 或 WebP。 |
| 压缩率 | 仅 JPEG、WebP 可填写 `0`～`100`，留空按 `100` 处理；PNG 不支持此参数。 |
| 背景 | 可选「自动」「不透明」「透明」。选择透明背景时，如果格式为 JPEG，页面会自动改为 PNG。 |

各供应商对模型和参数的支持可能不同。若服务返回不支持的参数，按错误提示调整，或恢复默认参数后重试。

## 查看和下载结果

下图展示输入「一只小猫」后的生图结果，可在预览区查看图片，并使用上方工具栏调整视图或下载。

![图片生成结果示例：小猫图片及预览、下载工具栏](/docs/assets/generate-image-result.png)

- 生成多张图片时，点击缩略图切换当前图片，再点击 **下载** 逐张保存。
- 可以用滚轮或放大、缩小按钮查看细节，也可以拖动画面、水平或垂直翻转；**重置视图** 可恢复初始显示。
- 缩放、拖动和翻转只影响预览，下载的仍是图像服务返回的原始图片。
- 如需继续修改生成结果，在参考图的 **历史记录** 弹窗中选择图片，填写新的修改要求。

左侧竖排图标可切换 **Chat** 和 **历史记录**，悬停可查看功能说明。历史记录按最新在前排列，最多保留最近 **10 张**已生成图片，支持点击预览、下载和删除。刷新后可以从历史记录中重新查看图片。

**请及时下载需要长期保留的图片。** 历史图片仅保存在当前浏览器，超过 10 张会自动移除最早的记录，清除浏览器数据也会丢失。若本地存储失败，页面会提示下载，生成结果仍可查看。刷新或离开页面后，尚未提交的提示词和当前参考图不会保留，已保存的供应商配置仍在当前浏览器中。

## 常见问题

| 遇到的问题 | 处理方式 |
| --- | --- |
| 「保存」按钮不可用 | 补全名称、Base URL、API Key，并至少选中一个模型。 |
| 模型下拉框为空，或没有想用的模型 | 打开当前供应商的编辑窗口，选中或添加对应模型后保存。 |
| 提示 Base URL 无效 | 使用公开的 HTTPS API 根地址；AlphaIO 为 `https://ai.alphaio.vip/v1`，不要填本机或内网地址。 |
| 提示当前模型不支持图生图 | 换用供应商支持编辑的模型，或移除参考图后改用文生图。 |
| 无法读取剪切板或上传失败 | 确认复制的是图片并允许剪切板访问，或改用「上传」；检查图片格式和 10MB 大小限制。 |
| 图像服务返回错误 | 查看提示中的服务端详情，核对当前供应商的地址、Key、余额、模型权限与参数。 |
| 超时、无法连接或没有返回图片 | 检查供应商服务状态，稍后重试；重复提交可能再次消耗额度。 |
