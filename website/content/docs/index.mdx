No need to juggle multiple subscriptions. Sign up, top up or redeem, create an API Key, then connect Claude Code, Codex, Cursor, and more to AlphaIO.
</Callout>

## Suggested path

Follow these four steps for your first successful request. Optional steps can wait until you need them.

<Steps>
<Step>

### Account

[Sign up](/docs/account/register) and [sign in](/docs/account/login) with email, GitHub, or Google to open the console.

</Step>
<Step>

### Top up / Redeem

[Top up](/docs/billing/topup) or [redeem](/docs/billing/redeem) for balance, then create an API Key for the right model group.

</Step>
<Step>

### Tool setup

Use [CC Switch](/docs/tools/cc-switch) for routing, or configure [Claude Code](/docs/tools/claude-code), [Codex](/docs/tools/codex), [Cursor](/docs/tools/cursor), and other clients directly.

</Step>
<Step>

### Extra capabilities (optional)

Install [Agent skills](/docs/ai/agent-skills) for in-chat images in Codex, or open [Image generation](/docs/image-generation) for the web studio. Stuck? See the [FAQ](/docs/faq).

</Step>
</Steps>
