# 切换 API 后 Codex 历史对话记录看不到了

打开 CC Switch 左上角的**设置**，进入**通用**，打开**统一 Codex 会话历史**。跨供应商继续会话时，服务端可能无法解密 Codex 的 `encrypted_content`，因此仍可能无法续接原会话。

![统一 Codex 会话历史](/docs/assets/ccswitch-history.png)

# 请求一直超时 / 连不上

1. 确认 API 地址可访问且 HTTPS 证书正常，检查是否填入了客户端要求的完整路径
2. 重新复制完整 API Key，并确认没有多余空格或换行
3. 检查账户余额、令牌分组和目标模型权限
4. 确认 CC Switch 的供应商、应用路由和总路由均已启用，再重启目标工具
5. 如果使用代理，检查代理、DNS 或节点是否拦截了目标域名；不要默认关闭代理

# CC Switch 切换后没生效

确保 CC Switch 的总路由、目标应用路由均为绿色，并且对应供应商已点击**启用**。
