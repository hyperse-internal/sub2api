---
title: 登录
icon: LogIn
description: 使用邮箱密码或第三方账号登录 AlphaIO 控制台。
---

已有账户时，打开 [https://ai.alphaio.vip/login](https://ai.alphaio.vip/login)：

1. 输入 **邮箱** 和 **密码**
2. 点击 **登录**

同样支持 **GitHub** / **Google** 快捷登录。若还没有账户，可在页面底部点击 **注册**，或先阅读 [注册](/docs/account/register)。

![登录页面](/docs/assets/login.png)

## 下一步

登录成功后：

1. 前往 [充值](/docs/billing/topup) 或 [兑换](/docs/billing/redeem) 获取额度
2. 创建 API Key，再按 [工具配置](/docs/tools/cc-switch) 接入客户端
