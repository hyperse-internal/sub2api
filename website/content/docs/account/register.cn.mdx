在 [ai.alphaio.vip](https://ai.alphaio.vip/login) 完成注册后，即可进入控制台进行充值、创建 API Key 等操作。

## 步骤

1. 打开登录页：[https://ai.alphaio.vip/login](https://ai.alphaio.vip/login)
2. 点击页面底部的 **注册**
3. 在「创建账户」表单中填写：
   - **邮箱**：用于登录与找回
   - **密码**：至少 6 个字符
   - **确认密码**：与密码保持一致
   - **优惠码**（可选）：有优惠码再填写
4. 点击 **继续** 完成注册

也可以点击 **GitHub** 或 **Google**，用第三方账号快速创建。

![注册页面](/docs/assets/register.png)

## 下一步

1. 前往 [登录](/docs/account/login) 进入控制台
2. 通过 [充值](/docs/billing/topup) 或 [兑换](/docs/billing/redeem) 获取额度
3. 创建 API Key 后，按 [工具配置](/docs/tools/cc-switch) 接入客户端
