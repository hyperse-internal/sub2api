## Redeem

Open [ai.alphaio.vip](https://ai.alphaio.vip), click **Redeem**, paste your code into the **Redeem code** field on the redeem page, then confirm. Balance usually appears after a refresh; if it does not update, sign in again or contact support to check redeem status.

![Redeem page](/docs/assets/redeem.png)

## Top up

Open [ai.alphaio.vip](https://ai.alphaio.vip), click **Top up / Subscribe**, and choose a plan. After payment succeeds, your balance appears.

![Top-up page](/docs/assets/purchase.png)

## Create an API Key

An API Key is your credential for configuring AI tools.

1. Click **API Keys** in the left menu
2. Click **Create key**
3. Enter any name (for your own reference)
4. In the group picker, choose a group that includes the models you need; group names and permissions follow what the site shows
5. Submit, then copy the full API Key (do not assume it must start with `sk-`)

![API Keys → Create key](/docs/assets/create-api.png)

**The group must match the models you need.** Groups control which models a token can access; follow the current model list and group notes on the site. If different tools need different groups or permissions, create separate tokens—do not reuse a Key that lacks the required access.

![Group selection — pick based on the models you will use](/docs/assets/select-group.png)
