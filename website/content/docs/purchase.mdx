## Redeem

Open [ai.alphaio.vip](https://ai.alphaio.vip), click **Redeem**, paste your code into the **Redeem code** field, then click **Redeem**.

![Redeem page](/docs/assets/redeem.png)

Common redeem-code types:

| Type | Effect |
| --- | --- |
| Balance | Adds account balance |
| Concurrency | Raises your concurrency limit |
| Subscription | Opens or renews a subscription group |

Balance and concurrency codes apply immediately. Balance usually appears after a refresh; if it does not update, sign in again or contact support to check redeem status.

### Subscription codes: confirm before redeeming

Subscription codes are not consumed right away. The site first shows a confirmation dialog with the impact and your current subscriptions (the group for this code is listed first and highlighted). Only **Continue** completes the redeem; **Cancel** leaves the code unused.

The dialog style and copy depend on whether you already have that group:

| Situation | Dialog style | What happens after redeem |
| --- | --- | --- |
| **New** (no subscription for that group yet) | Green notice | Creates a new subscription for the group; the term starts at redeem time |
| **Replace on renewal** (you already have the group, and it uses **Restart subscription on renewal**) | Amber warning | **Replaces** the current term: unused quota is cleared and reissued, and the term restarts from now; remaining time and quota from the old term are forfeited |
| **Extend** (you already have the group, without that policy) | Amber notice | **Extends** the current expiry; existing usage is kept |

**New subscription** example (green notice; Continue uses the primary button):

![Subscription redeem confirm — new](/docs/assets/redeem-subscription-new.png)

**Replace on renewal** example (amber warning; Continue uses the red danger button):

![Subscription redeem confirm — overwrite](/docs/assets/redeem-subscription-overwrite.png)

Subscriptions in other groups are not affected. If the dialog warns about replacement, confirm whether you still need the remaining quota before you continue.

## Top up / buy a subscription

Open [ai.alphaio.vip](https://ai.alphaio.vip), click **Top up / Subscribe**:

- **Balance top-up**: pay an amount; balance credits after success.
- **Subscription plan**: buy a plan; payment success opens or renews the matching group subscription.

![Top-up page](/docs/assets/purchase.png)

### Two renewal policies for subscriptions

Follow the plan-card notice and the group’s configuration:

| Policy | Behavior |
| --- | --- |
| **Default: extend expiry** | Buying again before expiry adds days to the current end date; daily / weekly / monthly usage and refresh windows stay as they are |
| **Restart subscription on renewal** | A successful purchase starts a new term immediately: expiry is recalculated from the effective time, and daily / weekly / monthly usage is reset; remaining time and unused quota from the old term are forfeited |

Plans that restart on renewal show a clear notice on the purchase card that remaining benefits will be forfeited. Read it before you pay.

Same as redeem: **only the purchased subscription group is affected**; other groups, account balance, and existing API Keys are unchanged.

Failed or unpaid checkouts do not change your current subscription. Duplicate payment callbacks do not reset or re-time the term again.

## Create an API Key

An API Key is your credential for configuring AI tools.

1. Click **API Keys** in the left menu
2. Click **Create key**
3. Enter any name (for your own reference)
4. In the group picker, choose a group that includes the models you need; group names and permissions follow what the site shows
5. Submit, then copy the full API Key (do not assume it must start with `sk-`)

![API Keys → Create key](/docs/assets/create-api.png)

**The group must match the models you need.** Groups control which models a token can access; follow the current model list and group notes on the site. If different tools need different groups or permissions, create separate tokens—do not reuse a Key that lacks the required access.

Subscription quotas are usually tied to a group: pick a subscription group you already have and that is still active (or another group the site allows).

![Group selection — pick based on the models you will use](/docs/assets/select-group.png)
