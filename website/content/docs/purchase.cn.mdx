## 兑换

打开 [ai.alphaio.vip](https://ai.alphaio.vip)，点击 **兑换**，将兑换码粘贴到「**兑换码**」输入框，再点 **兑换**。

![兑换页面](/docs/assets/redeem.png)

兑换码常见类型：

| 类型 | 效果 |
| --- | --- |
| 余额 | 增加账户余额 |
| 并发 | 提高并发上限 |
| 订阅 | 开通或续期某个订阅分组 |

余额、并发类兑换码提交后直接生效。通常刷新页面即可看到结果；若未更新，请重新登录，或联系站点支持核查兑换状态。

### 订阅类兑换码：确认后再兑换

订阅类兑换码不会立刻消耗。系统会先弹出确认框，说明本次影响，并列出你当前的订阅（本次兑换对应的分组会排在首位并高亮）。确认后才会真正兑换；点 **取消兑换** 则不消耗兑换码。

确认框会按「是否已有该分组订阅」显示不同样式与说明：

| 场景 | 弹窗样式 | 兑换后会发生什么 |
| --- | --- | --- |
| **新开通**（你还没有该分组订阅） | 绿色提示 | 为该分组新开通一套订阅，有效期从兑换时起算 |
| **覆盖续期**（该分组已有订阅，且分组开启了「续费时重新开始订阅」） | 琥珀色警告 | **覆盖**现有订阅：未使用额度清零并重新发放，有效期从兑换时重新计算；旧周期剩余时间与额度作废 |
| **延长续期**（该分组已有订阅，但未开启上述策略） | 琥珀色提示 | 在现有到期时间上**延长**天数，已用额度保留 |

**新开通**示例（绿色提示，「继续兑换」为主色按钮）：

![订阅兑换确认 — 新开通](/docs/assets/redeem-subscription-new.png)

**覆盖续期**示例（琥珀色警告，「继续兑换」为红色危险按钮）：

![订阅兑换确认 — 覆盖已有订阅](/docs/assets/redeem-subscription-overwrite.png)

其他分组的订阅不受影响。若弹窗提示覆盖，请先确认旧周期剩余额度是否还需要使用，再点 **继续兑换**。

## 充值 / 购买订阅

打开 [ai.alphaio.vip](https://ai.alphaio.vip)，点击 **充值/订阅**：

- **余额充值**：选择金额付款，成功后余额到账。
- **订阅套餐**：选择套餐购买；付款成功后开通或续期对应分组订阅。

![充值页面](/docs/assets/purchase.png)

### 订阅续费有两种策略

具体以套餐卡片上的提示、以及该订阅分组的配置为准：

| 策略 | 表现 |
| --- | --- |
| **默认：延长有效期** | 未到期再次购买时，在原到期时间上累加天数；日 / 周 / 月已用额度与刷新节奏保持不变 |
| **续费时重新开始订阅** | 成功购买后立即开始新周期：有效期从付款生效时重算，日 / 周 / 月用量清零；旧周期剩余时间与未使用额度作废 |

若套餐属于「续费时重新开始订阅」，购买页会用醒目提示提前说明「剩余权益将作废」。请在付款前阅读该提示。

与兑换相同：**只影响当前购买的订阅分组**；其他分组、账户余额、已有 API Key 不受影响。

支付失败或未支付不会改变现有订阅。重复支付回调不会重复清零或重复计时。

## 创建 API Key

API Key 就是你的「密钥」，后面配置 AI 工具时要用到它。

1. 点击左侧菜单「**API 密钥**」
2. 点击「**创建密钥**」
3. 随便输个名称（方便自己辨认即可）
4. 在分组中选择包含目标模型的分组，分组名称和权限以当前站点显示为准
5. 点提交，复制完整的 API Key（不要假定必须以 `sk-` 开头）

![API 密钥 → 创建密钥](/docs/assets/create-api.png)

**分组要与模型匹配。** 分组决定令牌可以访问哪些模型，请以站点当前的模型列表和分组说明为准。若不同工具需要不同分组或权限，请分别创建令牌，不要复用不具备对应权限的 Key。

订阅类额度通常绑定在对应分组上：请选择你已开通、且仍在有效期内的订阅分组（或站点说明允许的其他分组）。

![分组选择 — 根据你要用的模型来选](/docs/assets/select-group.png)
