打开 [ai.alphaio.vip](https://ai.alphaio.vip)，点击 **充值/订阅**：

- **余额充值**：选择金额付款，成功后余额到账。
- **订阅套餐**：选择套餐购买；付款成功后开通或续期对应分组订阅。

![充值页面](/docs/assets/purchase.png)

若已有兑换码，请改走 [兑换](/docs/billing/redeem)。

## 订阅续费有两种策略

具体以套餐卡片上的提示、以及该订阅分组的配置为准：

| 策略 | 表现 |
| --- | --- |
| **默认：延长有效期** | 未到期再次购买时，在原到期时间上累加天数；日 / 周 / 月已用额度与刷新节奏保持不变 |
| **续费时重新开始订阅** | 成功购买后立即开始新周期：有效期从付款生效时重算，日 / 周 / 月用量清零；旧周期剩余时间与未使用额度作废 |

若套餐属于「续费时重新开始订阅」，购买页会用醒目提示提前说明「剩余权益将作废」。请在付款前阅读该提示。

**只影响当前购买的订阅分组**；其他分组、账户余额、已有 API Key 不受影响。

支付失败或未支付不会改变现有订阅。重复支付回调不会重复清零或重复计时。

## 创建 API Key

API Key 就是你的「密钥」，后面配置 AI 工具时要用到它。充值或 [兑换](/docs/billing/redeem) 成功后，按以下步骤创建：

1. 点击左侧菜单「**API 密钥**」
2. 点击「**创建密钥**」
3. 随便输个名称（方便自己辨认即可）
4. 在分组中选择包含目标模型的分组，分组名称和权限以当前站点显示为准
5. 点提交，复制完整的 API Key（不要假定必须以 `sk-` 开头）

![API 密钥 → 创建密钥](/docs/assets/create-api.png)

**分组要与模型匹配。** 分组决定令牌可以访问哪些模型，请以站点当前的模型列表和分组说明为准。若不同工具需要不同分组或权限，请分别创建令牌，不要复用不具备对应权限的 Key。

订阅类额度通常绑定在对应分组上：请选择你已开通、且仍在有效期内的订阅分组（或站点说明允许的其他分组）。

![分组选择 — 根据你要用的模型来选](/docs/assets/select-group.png)
