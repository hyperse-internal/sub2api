---
title: 注册账号
description: 在 AlphaIO 创建账户并登录，为后续充值与工具接入做准备。
---

在 [ai.alphaio.vip](https://ai.alphaio.vip/login) 完成注册与登录后，即可进入控制台进行充值、创建 API Key 等操作。

## 注册

1. 打开登录页：[https://ai.alphaio.vip/login](https://ai.alphaio.vip/login)
2. 点击页面底部的 **注册**
3. 在「创建账户」表单中填写：
   - **邮箱**：用于登录与找回
   - **密码**：至少 6 个字符
   - **确认密码**：与密码保持一致
   - **优惠码**（可选）：有优惠码再填写
4. 点击 **继续** 完成注册

也可以点击 **GitHub** 或 **Google**，用第三方账号快速创建。

![注册页面](/docs/assets/register.png)

## 登录

已有账户时，打开同一入口 [https://ai.alphaio.vip/login](https://ai.alphaio.vip/login)：

1. 输入 **邮箱** 和 **密码**
2. 点击 **登录**

同样支持 **GitHub** / **Google** 快捷登录。若还没有账户，可在页面底部点击 **注册**。

![登录页面](/docs/assets/login.png)

## 下一步

登录成功后：

1. 前往 [充值或兑换](/docs/purchase) 获取额度
2. 创建 API Key，再按 [配置工具](/docs/config-tool) 接入客户端
