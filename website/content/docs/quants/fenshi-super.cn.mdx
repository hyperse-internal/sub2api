产品页：[https://www.alphaio.vip/features/fenshi_super](https://www.alphaio.vip/features/fenshi_super)

超级分时按 **分时几何结构** 在分钟级标出低吸 / 强买 / 高抛 / 快跑，点位直接落在分时图上。不看 L2 资金闸；**纯信号**，不含持仓与成交回写。

<Callout title="怎么进" type="info">
**未开通**：产品页订阅区选盯盘槽位并结算。  
**已开通**：顶部 **我的订阅** → **超级分时** → **进入**（详见 [开始使用](/docs/quants/getting-started)）。
</Callout>

<Callout title="与龙头分时独立" type="info">
超级分时与龙头分时是两套独立引擎、独立盯盘槽位、独立计费。本页看不到对方的点位。
</Callout>

## 适合谁

- 希望自主看盘与交易，需要多标的分时结构参考
- 接受网页内弹窗 / 提示音，不依赖飞书推送
- 不需要系统帮你记底仓或股数建议

## 开始前准备

1. 完成 [开始使用](/docs/quants/getting-started) 中的邀请码注册与登录
2. 已开通超级分时盯盘槽位（未开通先到产品页订阅）
3. 准备好要盯的股票代码 / 名称 / 拼音

## 进入盯盘台

1. 打开 **我的订阅**
2. 在 **特色功能 PATTERN** 找到 **超级分时**
3. 点击 **进入**

也可从 [产品页](https://www.alphaio.vip/features/fenshi_super) 进入同一工作台。

## 开通盯盘槽位

1. 在产品页下滑到 **订阅区**，选择月付档（按「可同时盯盘的标的数」计槽）
2. 进入结算页完成支付
3. 返回后确认槽位条，例如「可同时看 N 只 · 已选 M 只」，并核对有效期

一槽对应一张可实时刷新的分时卡；超出槽位的票可留在清单里，但卡片会置灰并暂停刷新。

## 添加 / 更换标的

在 **分时盯盘** 工具栏：

1. 在 **添加标的** 输入代码、名称或拼音（如 `lxgf`）
2. 在下拉结果中点选目标股票
3. 选中后加入当前盯盘清单

![添加标的：拼音搜索与下拉选择](/docs/assets/quants/fenshi-add-symbol.png)

**槽位满了怎么换票：** 先从清单中移除不需要的标的（在卡片或清单操作里删除 / 移出），使「已选」低于「可同时看」，再添加新票。不要指望多开超出配额的实时卡。

## 盯盘界面

| 控件 | 作用 |
| --- | --- |
| 添加标的 | 搜索并加入股票 |
| 网格布局（如 `2 x 2`） | 一屏显示几只 |
| 提醒 | 新点位网页弹窗 |
| 声音 | 买卖提示音 |
| 槽位条 | 「可同时看 N 只 · 已选 M 只」与有效期 |
| `每 15s 刷新` / 刷新 | 自动轮询与手动刷新 |

每张分时卡通常包含：名称与代码、现价涨跌、高低点、价格线 / 均价线 / 昨收、点位标记与说明、当日点位数量等。

![超级分时盯盘：双卡同屏与高抛点位](/docs/assets/quants/fenshi-workbench.png)

## 点位怎么读

| 点位 | 大致含义（结构提示，非下单指令） |
| --- | --- |
| **低吸** | 价格相对均价偏弱后出现回踩企稳类结构 |
| **强买** | 均价上方偏强、突破或放量推进类结构 |
| **高抛** | 冲高后滞涨、回落类结构 |
| **快跑** | 偏弱加速、需警惕回撤类结构 |

点位是分钟级结构信号，**不含股数与持仓**；仓位由你自行决定。它与智T飞书里的「低吸 / 高抛」文案相似，但是 **网页盯盘产品**，不会推飞书、也不登记底仓。

## 提醒与声音

打开工具栏 **提醒** / **声音** 后，新点位会弹窗，并用不同音色区分买卖方向。

<Callout title="没有飞书推送" type="info">
超级分时目前只有网页弹窗与提示音。需要飞书跟仓推送请用 [智T引擎](/docs/quants/follow-t-assist)。
</Callout>

## 日常用法

1. **开盘前**：从「我的订阅」进入，加好标的，确认已选 ≤ 可同时看
2. **盘中**：同屏看图；听到提示后核对对应卡片
3. **决策**：自主下单（平台不代下单）
4. **收盘后**：可回顾当日点位；无需维护底仓

## 常见问题

**加票后卡片是灰的？**  
「已选」超过「可同时看」。删票或升级槽位。

**和龙头分时有什么区别？**  
龙头分时叠加龙头识别与 L2 资金过滤；超级分时不做 L2 闸。需分别开通。

**为什么没有飞书？**  
本产品不做飞书；飞书属于智T。

**没有新点位？**  
先确认登录与权益、点「刷新」。当日未触发结构时也可能一直没有点位。
