Portal 站点：[https://www.alphaio.vip](https://www.alphaio.vip/)

登录与注册在同一页切换：  
[https://www.alphaio.vip/login](https://www.alphaio.vip/login?callbackUrl=%2Fhome)

产品介绍页可以匿名打开；**盯盘台 / 智T管理台**需要登录。

## 入口怎么选

| 你的状态 | 怎么走 |
| --- | --- |
| 还没账号 | 下面「邀请码注册」→ 邮箱验证 → 登录 |
| 已登录，还没开通产品 | 「功能大厅」看介绍并订阅，或打开产品页结算 |
| 已经开通 | 「我的订阅」→ 对应行点 **进入**（最快） |

## 邀请码注册

Portal **仅支持邮箱 + 邀请码注册**。没有邀请码时，需先联系客服 / 运营获取。

1. 打开 [登录页](https://www.alphaio.vip/login?callbackUrl=%2Fhome)
2. 切换到顶部标签 **邀请码注册**
3. 按表单填写：
   - **邀请码**（必填）：格式示意 `INVITE-XXXX-XXXX`
   - **邮箱**（必填）
   - **密码**（必填）：至少 6 位
   - **昵称**（可选）
4. 勾选同意《服务使用与风险告知协议》（本站为信息技术工具，不荐股、不构成投资建议）
5. 点击 **注册**
6. 查收验证邮件并完成验证，再登录

没有邀请码时可点「没有邀请码？请联系客服获取」，或直接联系运营。

![邀请码注册页](/docs/assets/quants/portal-register.png)

### 注册说明

- 提交后必须完成 **邮箱验证** 才能正常登录
- 未收到邮件时请检查垃圾箱，或重新发送验证邮件
- 登录用于核验账户权益，不改变盘后数据口径

## 登录

1. 打开 [https://www.alphaio.vip/login](https://www.alphaio.vip/login?callbackUrl=%2Fhome)
2. 确认顶部标签为 **登录**
3. 输入 **邮箱**、**密码**
4. 按需勾选 **保持登录**
5. 点击 **登录**（成功后一般进入首页）

忘记密码：点击 **忘记密码?**，按邮件完成重置。

![登录页](/docs/assets/quants/portal-login.png)

## 从「我的订阅」进入（已开通推荐）

1. 登录后打开顶部导航 **我的订阅**（首页订阅列表，地址多为 [https://www.alphaio.vip/home](https://www.alphaio.vip/home)）
2. 找到分区 **特色功能 PATTERN**
3. 在对应行点 **进入**：
   - **智T引擎**（另可有详情 / 续费）
   - **超级分时**

状态一般为「已开通」，并显示有效期。

![我的订阅：智T引擎与超级分时入口](/docs/assets/quants/portal-subscriptions.png)

## 从功能大厅进入（未开通或先看介绍）

1. 打开 [功能大厅](https://www.alphaio.vip/features)
2. 筛选特色功能：  
   [https://www.alphaio.vip/features?domain=pattern](https://www.alphaio.vip/features?domain=pattern)
3. 点击产品卡片：
   - [超级分时](https://www.alphaio.vip/features/fenshi_super)
   - [智T引擎](https://www.alphaio.vip/features/follow_t_assist)

未登录可先浏览介绍；登录后可订阅并使用工作台。

## 开通槽位

在产品页的订阅区选择 **月付槽位档**，进入结算完成支付：

- 超级分时 → **盯盘槽位**（一槽约对应一张实时分时卡）
- 智T引擎 → **跟仓槽位**（一槽约对应一条有效跟仓腿）

开通后回到「我的订阅」用 **进入** 打开工作台。
