产品页：[https://www.alphaio.vip/features/follow_t_assist](https://www.alphaio.vip/features/follow_t_assist)

智T引擎用同源分时确认算法捕捉低吸 / 高抛 / 反转，经服务端分钟信号后以 **飞书** 推送；**人机协同**，由你自行下单。按 **跟仓槽位** 月付。

<Callout title="怎么进" type="info">
**未开通**：产品页选跟仓槽位并结算。  
**已开通**：顶部 **我的订阅** → **智T引擎** → **进入**（详见 [开始使用](/docs/quants/getting-started)）。
</Callout>

<Callout title="推荐顺序" type="warn">
请按：**配置飞书并测试通过 → 加票 → 登记底仓 → 盘中看飞书 / 管理台复盘**。  
先加票却未配飞书，盘中往往收不到提醒。
</Callout>

<Callout title="接收端是飞书" type="info">
网页管理台负责加票、底仓与复盘；盘中提醒以飞书群机器人为准，不是靠网页不停刷新。
</Callout>

## 适合谁

- 已有关注标的，希望盘中用飞书收提醒再手动执行
- 需要票池状态与信号复盘在同一管理台
- 接受提醒可能略有延迟

## 信号缩写对照

飞书卡片多用中文意图；管理台列表常见缩写：

| 缩写 | 常见含义 |
| --- | --- |
| **TB** | 低吸（买入）类建议 |
| **TS** | 高抛（卖出）类建议 |
| **RB** | 反转低吸类建议 |
| **RS** | 反转高抛类建议 |
| **EXIT** / 清仓提示 | 触及风控后的清仓类建议 |

具体以卡片「意图 / 说明」字段为准；均为提醒，不代下单。

## 开始前准备

1. 完成 [开始使用](/docs/quants/getting-started)
2. 准备飞书群 **自定义机器人**链接（Webhook，形如 `https://open.feishu.cn/...`）
3. 从 **我的订阅 → 进入** 打开管理台

## 开通跟仓槽位

1. 产品页订阅区选择月付档并结算
2. 确认管理台可用；顶部可见「信号 x/y」等用量与有效期
3. 不够时点 **升级槽位**

一槽对应一条有效跟仓腿；**释放** 可腾出槽位。

顶部若同时出现 **信号** 与 **QMT** 两套用量：它们是独立权益。只用智T信号档时，保持在 **信号模式**；未开通智T·QMT 时不要切到 QMT 模式（否则会提示未开通或槽位不可用）。

## ① 策略设置：先配飞书

**策略设置 → 飞书通知**：

1. 飞书建群 → 添加自定义机器人 → 复制 Webhook
2. 粘贴到输入框 → **保存 Webhook**（留空 = 不推送）
3. 点测试确认群里能收到：
   - **测试·辅助**（信号档常用）
   - **测试·QMT成交**（仅 QMT 线需要）
   - **测试·清仓**
4. 再按需设置 **推送开关**、**清仓风控**（全局默认，可被个股覆盖）

![策略设置：飞书 Webhook 与测试推送](/docs/assets/quants/follow-t-settings.png)

## ② 跟踪票池：添加股票

在 **跟踪票池**：

1. 确认当前为 **信号模式**（有 QMT 权益再切 QMT）
2. **加票** 输入代码 / 名称 / 拼音，点选结果（占用 1 个跟仓槽位）

![跟踪票池：拼音搜索加票](/docs/assets/quants/follow-t-add-symbol.png)

筛选项里的 **新票分时（如「超级分时」）** 表示这条跟仓腿选用的分时引擎标签，**不等于**你已单独开通「超级分时」盯盘商品。两个产品的清单与槽位仍然独立。

## ③ 登记底仓

加票后，在该行点 **登记底仓**：

1. 填 **底仓手数**
2. 填 **锚定价格（元）**
3. 点 **确认**

确认后：该腿进入可跟踪状态、继续占用跟仓槽位，后续飞书建议股数与复盘统计会参考这份底仓。仍须你自己在券商侧下单。

之后可调整底仓，或 **释放** 腾出槽位。

![登记底仓弹窗](/docs/assets/quants/follow-t-register-base.png)

## ④ 盘中使用（看飞书）

1. 分钟信号产生后，飞书群收到卡片
2. 对照真实持仓，**自主下单**
3. 再到管理台 **盘中信号** 核对；需要时可补录（手工补一条记录，便于复盘完整）

### 飞书卡片长什么样

常见字段：通道、分时类型、时刻、标的、意图、动作、建议股数、参考价、持仓 / 底仓、成本、触发说明。页脚注明非荐股、买卖自负。

![飞书盘中建议卡片示意](/docs/assets/quants/follow-t-feishu-card.png)

## ⑤ 盘中信号 · 分时对照 · 高抛低吸明细

打开 **盘中信号**：

1. 右上角切换标的
2. 看收益摘要与累计曲线
3. 在表中查看 TB / TS / RB / RS / EXIT 等记录
4. 行内 **分时对照**：信号落在分时图哪一分钟
5. **高抛低吸明细**：买卖数量与分时标记并排核对

![盘中信号：摘要、曲线与信号表](/docs/assets/quants/follow-t-signals.png)

![高抛低吸明细与分时落点](/docs/assets/quants/follow-t-detail.png)

## 单票回测（可选）

用于按日期回看策略行为，**不构成收益承诺**。日常以飞书 + 盘中信号为准。

## 常见问题

**飞书收不到？**  
先确认已 **保存** Webhook 并用「测试·辅助」；再查推送开关与该腿状态。

**槽位已满？**  
释放不用的腿，或升级。确认当前是信号模式且信号档已开通。

**和超级分时一起用？**  
可以，但是两套订阅：网页盯盘用超级分时，飞书跟仓用智T。

**为什么要登记底仓还要自己下单？**  
底仓服务信号尺度与复盘；平台不代客下单。
