# 智T·QMT

## 产品名称

智T·QMT

## 产品介绍

智T·QMT 是面向本地 QMT 执行的做 T 产品。按官方介绍，客户侧 Worker 使用与信号档同源的分时确认算法，在本地完成决策并通过 QMT 下单；服务端负责槽位管理和成交回写，以实际成交记录为账本，再通过飞书发送成交回报。

**上线状态需注意**：页面同时注明，Worker 包与鉴权上线后才按实际成交进行历史复盘，当前可先占用 QMT 槽位登记标的。因此，下述自动执行链路属于页面介绍的产品能力，本次不能据此确认其已完整开放。

[智T·QMT 官方详情页](https://www.alphaio.vip/features/follow_t_qmt)

## 产品功能

- **同源分时确认**：使用与信号档及平台自用做 T 相同来源的算法。
- **本地决策与执行**：客户侧 Worker 在本地决策，经 QMT 下单；页面展示的链路为分时确认、Worker 决策、QMT 下单、成交回写、飞书卡片。
- **成交回写与记录**：将成交记录（fill）回写服务端，作为唯一账本依据，用于成交历史复盘。
- **成交回报通知**：飞书卡片展示通道、分时类型、时刻、标的、意图、成交股数与价格、回写状态及成本信息。
- **成交落点与明细**：页面展示 QMT 买卖落点、当日成交明细及高低配对的复盘形态。
- **独立槽位管理**：按并发跟踪标的数配置 QMT 槽位，可与信号档叠加。页面说明当前可先登记标的。

## 产品特点

- **客户端执行**：Worker 和 QMT 位于客户侧，服务端不替代用户的券商通道。
- **以实际成交为依据**：以成交回写记录建立账本，区分信号意图和实际执行结果。
- **独立订阅**：QMT 槽位与信号槽位独立，可叠加使用。
- **按槽位月付**：提供 2、4、6、8、10、12 槽位档位，按并发可跟踪标的数计费。
- **飞书接收回报**：页面说明不配置飞书仍可运行下单链路，但无法通过飞书查看成交回报与做 T 增厚信息；实际执行开放状态仍以上述上线提示为准。

## 产品优势

以下根据页面介绍归纳，依赖对应执行能力正式开放及正确部署。

- **衔接信号与执行**：由本地 Worker 将算法结果连接到 QMT 下单流程，减少人工转录环节。
- **便于成交核对**：以实际成交而非仅有信号作为复盘依据。
- **执行位置明确**：通过用户自己的 QMT 和券商通道完成交易。
- **可组合使用**：独立 QMT 槽位可与信号档叠加，支持不同执行方式的组合需求。

## 产品适用场景

以下为根据产品定位归纳的使用场景，正式执行前需确认 Worker、鉴权及所需交易环境已可用。

- 拥有可用 QMT 环境，希望接入本地做 T 执行流程。
- 希望从人工接收信号扩展到 Worker 本地决策和执行。
- 需要按实际成交核对买卖记录、复盘分时落点。
- 希望通过飞书集中接收本地执行后的成交回报。
