# 生产部署（编排）

覆盖升级 `https://ai.alphaio.vip`（主机 `103.24.219.58`；）：换 Go 二进制 + 文档站（website SSR），配置和数据不动。本文只编排顺序，命令与判定在分步文档里。

## 线上布局

| 项 | 值 |
| --- | --- |
| 面板 | systemd `sub2api`，`/opt/sub2api/bin/server`（Vue 面板 embed） |
| 文档站 | PM2 `alphaio-docs`，`/opt/sub2api/website/`，监听 `127.0.0.1:3001` |
| 入口 | Nginx → `/tools`、`/cn/tools`、`/docs`、`/cn/docs`、`/docs-assets/`、`/docs-api/` → docs；其余 → `127.0.0.1:8080` |
| 配置 | `/opt/sub2api/config.yaml`、`.env`、`.installed`；`.env` 中 `DATA_DIR=/opt/sub2api` |
| 对照副本 | `docs/deploy/config/`（含 `ai.alphaio.vip`、`ecosystem.config.cjs`） |
| 日志 | Go：`logs/sub2api.log`、`logs/stderr.log`；文档：`logs/alphaio-docs-*.log` |
| 数据 | PostgreSQL `sub2api`；Redis DB 1 |
| 备份 | `/opt/sub2api/backup/<时间戳>/`，旧目录人工清理 |

文档站与 Go **解耦**：website 不 embed 进二进制；Nginx 分流，不经 Go 反代。

## 会话变量

在仓库根目录、同一个终端里执行全部步骤。先定义：

```bash
PEM="docs/server/server.pem"
HOST="root@103.24.219.58"
SSH=(ssh -i "$PEM" -o IdentitiesOnly=yes -o StrictHostKeyChecking=accept-new -o ConnectTimeout=30)
TS="$(date +%Y%m%d-%H%M%S)"   # 本次部署的备份目录名，回滚也用它
```

SSH 偶发 `Connection closed`：隔几秒重试。
