# 环境检测

确认生产机可达、布局正常。变量见 [生产部署.md](./生产部署.md#会话变量)。

```bash
"${SSH[@]}" "$HOST" 'set -euo pipefail
systemctl is-active sub2api
test -x /opt/sub2api/bin/server
test -f /opt/sub2api/config.yaml
test -f /opt/sub2api/.env
test -f /opt/sub2api/.installed
grep -qx "DATA_DIR=/opt/sub2api" /opt/sub2api/.env
if grep -q "^AUTO_SETUP=" /opt/sub2api/.env; then echo "AUTO_SETUP present"; exit 1; fi
test ! -e /app/data
curl -fsS http://127.0.0.1:8080/health
redis-cli -n 1 PING
sudo -u postgres psql -d sub2api -c "SELECT 1" >/dev/null
echo ok
'
```

通过标准：最后输出 `ok`。中途退出时，最后一行命令就是失败项，先排查，不要部署。
