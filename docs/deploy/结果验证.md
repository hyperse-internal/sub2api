# 结果验证

在 [服务器部署.md](./服务器部署.md) 第 3 步之后执行。变量见 [生产部署.md](./生产部署.md#会话变量)。

```bash
"${SSH[@]}" "$HOST" "set -euo pipefail
/opt/sub2api/bin/server --version
systemctl is-active sub2api
systemctl show -p NRestarts --value sub2api
pm2 describe alphaio-docs >/dev/null
curl -fsS -o /dev/null -w 'public=%{http_code}\n' https://ai.alphaio.vip/health
curl -fsS -o /dev/null -w 'docs=%{http_code}\n' https://ai.alphaio.vip/docs
curl -fsS -o /dev/null -w 'docs_cn=%{http_code}\n' https://ai.alphaio.vip/cn/docs
curl -fsS -o /dev/null -w 'docs_search=%{http_code}\n' 'https://ai.alphaio.vip/docs-api/search?query=register'
B=/opt/sub2api/backup/$TS
for f in config.yaml .env .installed; do cmp /opt/sub2api/\$f \$B/\$f; done
PID=\$(systemctl show -p MainPID --value sub2api)
tr '\0' '\n' < /proc/\$PID/environ | grep -qx 'DATA_DIR=/opt/sub2api'
test ! -e /app/data
tail -n 30 /opt/sub2api/logs/stderr.log
grep -wE 'ERROR|FATAL|PANIC' /opt/sub2api/logs/sub2api.log | tail -n 20 || true
tail -n 20 /opt/sub2api/logs/alphaio-docs-error.log 2>/dev/null || true
echo ok
"
```

## 通过标准

| 项 | 期望 |
| --- | --- |
| `--version` | commit 与 [构建.md](./构建.md) 里 `git log -1` 一致 |
| `is-active` / `NRestarts` | `active` / `0` |
| `pm2 describe alphaio-docs` | 进程存在且 online |
| 公网 health | `public=200` |
| 公网文档 | `docs=200`、`docs_cn=200`（fumadocs，非面板页） |
| 公网搜索 | `docs_search=200`（JSON；勿落到 Go `/api`） |
| 配置比对 | `cmp` 无输出（三份配置与备份相同） |
| 进程环境 | 含 `DATA_DIR=/opt/sub2api`，`/app/data` 不存在 |
| 日志 | `stderr.log` / `sub2api.log` 的 ERROR 时间早于本次重启；docs error 日志无持续刷错 |
| 结尾 | 输出 `ok` |

再用管理员账号登录 `https://ai.alphaio.vip`，确认用户、渠道、设置与管理页正常；浏览器打开 `/docs`，确认侧栏搜索可用。

## 失败处理

| 现象 | 处理 |
| --- | --- |
| health 不通、`NRestarts` 增长、日志有迁移 checksum 错误 | 回滚 Go 二进制 |
| `/docs` 502 / 非 200，本机 `:3001` 不通 | `pm2 logs alphaio-docs`，按 [服务器部署.md](./服务器部署.md#42-回滚-website) 回滚 website |
| 本机 `:3001` 正常、公网 `/docs` 非 200 | 查 Nginx 分流（`/docs`、`/docs-assets/`、`/docs-api/`），对照 `config/ai.alphaio.vip` |
| `/docs-api/search` 404 或进了面板 | Nginx 未加 `/docs-api/`，或 website 仍用旧路径 `/api/search` |
| `/docs` 样式丢失、资源 404 | 漏传 `docs-assets` 或 Nginx 未代理 `/docs-assets/` |
| `cmp` 报配置不同 | 立即停止，从 `backup/$TS/` 恢复配置后再评估 |
| 管理页是旧的 | 漏了 `-tags embed` 或传错 Go 包，重新构建 |
