# 服务器部署

备份 → 上传 → 替换 → 重启。变量 `PEM` / `HOST` / `SSH` / `TS` 见 [生产部署.md](./生产部署.md#会话变量)。

含两部分，可同一次发布一起做：

| 部分 | 动作 |
| --- | --- |
| Go 面板 | `server.new` → `mv` → `systemctl restart sub2api` |
| website 文档 | rsync 到 `/opt/sub2api/website/` → `pm2 reload alphaio-docs` |

## 1. 备份

只在本次部署开始时执行一次。替换后失败需要重试时，从第 2 步开始，否则新备份里存的就是坏掉的新包。

```bash
"${SSH[@]}" "$HOST" "set -euo pipefail
B=/opt/sub2api/backup/$TS
install -d -m 700 \$B
cp -a /opt/sub2api/bin/server /opt/sub2api/config.yaml /opt/sub2api/.env /opt/sub2api/.installed \$B/
# 文档站（若已安装）
if [ -d /opt/sub2api/website/build ]; then
  tar -C /opt/sub2api -czf \$B/website-build.tgz website/build website/package.json website/pnpm-lock.yaml website/ecosystem.config.cjs 2>/dev/null || \
  tar -C /opt/sub2api -czf \$B/website-build.tgz website/build
fi
sudo -u postgres pg_dump -Fc -d sub2api > \$B/sub2api.dump
chmod 600 \$B/sub2api.dump
ls -l \$B
"
```

## 2. 上传

### 2.1 Go 二进制

```bash
scp -i "$PEM" -o IdentitiesOnly=yes -o StrictHostKeyChecking=accept-new \
  backend/server "$HOST:/opt/sub2api/bin/server.new"
LOCAL_SHA="$(shasum -a 256 backend/server | cut -d' ' -f1)"
"${SSH[@]}" "$HOST" "echo '$LOCAL_SHA  /opt/sub2api/bin/server.new' | sha256sum -c -"
```

sha256 不一致：重新 scp，不要进入第 3 步。

### 2.2 website 文档站

本机已按 [构建.md](./构建.md) 编好 `website/build/`。打包生产运行所需文件（含 `node_modules`，避免在生产机再装依赖）：

```bash
cp -f docs/deploy/config/ecosystem.config.cjs website/ecosystem.config.cjs
tar -C website -czf /tmp/website-release.tgz \
  package.json pnpm-lock.yaml .npmrc ecosystem.config.cjs build node_modules
scp -i "$PEM" -o IdentitiesOnly=yes -o StrictHostKeyChecking=accept-new \
  /tmp/website-release.tgz "$HOST:/tmp/website-release.tgz"
"${SSH[@]}" "$HOST" 'set -euo pipefail
install -d /opt/sub2api/website
# 先清旧 build，避免残留旧 hash 资源
rm -rf /opt/sub2api/website/build
tar -C /opt/sub2api/website -xzf /tmp/website-release.tgz
rm -f /tmp/website-release.tgz
test -f /opt/sub2api/website/build/server/index.js
test -d /opt/sub2api/website/build/client/docs-assets
test -f /opt/sub2api/website/ecosystem.config.cjs
'
```

## 3. 替换并重启

### 3.1 Go

```bash
"${SSH[@]}" "$HOST" 'set -euo pipefail
chmod 755 /opt/sub2api/bin/server.new
mv /opt/sub2api/bin/server.new /opt/sub2api/bin/server
systemctl restart sub2api
for i in $(seq 1 30); do
  curl -fsS http://127.0.0.1:8080/health >/dev/null 2>&1 && break
  sleep 2
done
curl -fsS http://127.0.0.1:8080/health
'
```

60 秒内 health 不通即失败（迁移较多时启动会慢一些），直接回滚。

### 3.2 website（PM2）

```bash
"${SSH[@]}" "$HOST" 'set -euo pipefail
test -f /opt/sub2api/website/build/server/index.js
test -f /opt/sub2api/website/ecosystem.config.cjs
cd /opt/sub2api/website
if pm2 describe alphaio-docs >/dev/null 2>&1; then
  pm2 reload ecosystem.config.cjs --update-env
else
  pm2 start ecosystem.config.cjs
  pm2 save
fi
for i in $(seq 1 30); do
  curl -fsS http://127.0.0.1:3001/docs >/dev/null 2>&1 && break
  sleep 2
done
curl -fsS -o /dev/null -w "docs_local=%{http_code}\n" http://127.0.0.1:3001/docs
curl -fsS -o /dev/null -w "search_local=%{http_code}\n" "http://127.0.0.1:3001/docs-api/search?query=docs"
pm2 describe alphaio-docs | head -n 20
'
```

本机 `3001` 不通：看 `pm2 logs alphaio-docs` / `logs/alphaio-docs-error.log`，不要改 Go 配置。

### 3.3 Nginx（仅配置有变更时）

对照仓库 `docs/deploy/config/ai.alphaio.vip` 更新站点配置后：

```bash
"${SSH[@]}" "$HOST" 'nginx -t && systemctl reload nginx'
```

日常只发 website/Go、Nginx 未改时跳过。

## 4. 回滚

### 4.1 回滚 Go 二进制

默认只回滚二进制，不回滚数据库；`pg_restore` 会丢掉升级后写入的数据，仅在明确要求时评估。

```bash
"${SSH[@]}" "$HOST" "set -euo pipefail
cp -a /opt/sub2api/backup/$TS/server /opt/sub2api/bin/server
systemctl restart sub2api
for i in \$(seq 1 30); do
  curl -fsS http://127.0.0.1:8080/health >/dev/null 2>&1 && break
  sleep 2
done
curl -fsS http://127.0.0.1:8080/health
"
```

### 4.2 回滚 website

```bash
"${SSH[@]}" "$HOST" "set -euo pipefail
B=/opt/sub2api/backup/$TS
test -f \$B/website-build.tgz
tar -C /opt/sub2api -xzf \$B/website-build.tgz
cd /opt/sub2api/website && pm2 reload ecosystem.config.cjs --update-env
curl -fsS -o /dev/null -w 'docs_local=%{http_code}\n' http://127.0.0.1:3001/docs
"
```
