# 构建

在本机交叉编译 linux/amd64 静态二进制，前端 embed 进去。需要 Go `1.27.2`（与 `backend/go.mod` 一致）、Node 18+、pnpm。

## 1. 确认代码已推送

```bash
git fetch origin
test -z "$(git status --porcelain -- backend frontend)"   # 代码目录无未提交改动
git branch -r --contains HEAD | grep -q .                  # HEAD 已在远端分支上
git log -1 --oneline
```

任一条失败就先提交、推送，不要用本地改动构建。

本次提交若含 SQL 迁移，确认只是加表 / 加列 / 加索引；有删改列、改数据的迁移先单独评估再发。

## 2. 编译

```bash
(cd frontend && pnpm run build)   # 产物：backend/internal/web/dist/

cd backend
VERSION="$(./scripts/resolve-version.sh)"
COMMIT="$(git rev-parse --short HEAD)"
DATE="$(date -u +%Y-%m-%dT%H:%M:%SZ)"
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 \
  go build -tags embed \
  -ldflags="-X main.Version=${VERSION} -X main.Commit=${COMMIT} -X main.Date=${DATE}" \
  -o server ./cmd/server
cd ..
```

## 3. 自检

```bash
file backend/server   # 期望：ELF 64-bit LSB executable, x86-64, statically linked
ls -lh backend/server # 期望：约 170MB+；几十 MB 说明前端没打进去，不要上传
```
