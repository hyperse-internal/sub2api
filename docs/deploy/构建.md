# 构建

在本机准备两份产物：

1. **Go 面板二进制**（交叉编译 linux/amd64，Vue 面板 embed）
2. **website 文档站**（SSR：`build/` + 生产依赖，由 PM2 运行）

需要 Go `1.27.2`（与 `backend/go.mod` 一致）、Node 18+、pnpm。

## 产物关系

| 源码 | 构建 | 运行时 |
| --- | --- | --- |
| `frontend/` | `pnpm run build` → `backend/internal/web/dist/` | embed 进 `server`，面板 `/` |
| `website/` | `pnpm run build` → `website/build/` | PM2 → `127.0.0.1:3001`；Nginx → `/docs`… |
| `backend/` | `go build -tags embed` → `backend/server` | systemd `sub2api` |

website **不要**再拷进 `backend/internal/web/docs-dist`；文档与 Go 解耦。

## 1. 确认代码已推送

```bash
git fetch origin
test -z "$(git status --porcelain -- backend frontend website)"   # 代码目录无未提交改动
git branch -r --contains HEAD | grep -q .                          # HEAD 已在远端分支上
git log -1 --oneline
```

任一条失败就先提交、推送，不要用本地改动构建。

本次提交若含 SQL 迁移，确认只是加表 / 加列 / 加索引；有删改列、改数据的迁移先单独评估再发。

## 2. 编译前端面板

```bash
(cd frontend && pnpm install --frozen-lockfile && pnpm run build)
# 产物：backend/internal/web/dist/index.html
test -f backend/internal/web/dist/index.html
```

## 3. 编译文档站（website）

```bash
(cd website && pnpm install --frozen-lockfile && pnpm run build)
# 产物：website/build/server/index.js 、 website/build/client/（含 docs-assets/）
test -f website/build/server/index.js
test -d website/build/client/docs-assets
```

自检静态资源目录名必须是 `docs-assets`（与 Nginx、面板 `/assets` 隔离）。

## 4. 编译后端（embed 面板）

```bash
cd backend
VERSION="$(./scripts/resolve-version.sh)"
COMMIT="$(git rev-parse --short HEAD)"
DATE="$(date -u +%Y-%m-%dT%H:%M:%SZ)"
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 \
  go build -tags embed \
  -ldflags="-X main.Version=${VERSION} -X main.Commit=${COMMIT} -X main.Date=${DATE}" \
  -o server ./cmd/server
cd ..
```

## 5. 自检

```bash
file backend/server   # 期望：ELF 64-bit LSB executable, x86-64, statically linked
ls -lh backend/server # 期望：明显大于「仅后端」；几十 MB 且明显偏小说明面板没 embed，不要上传
ls -lh website/build/server/index.js website/build/client/docs-assets | head
```
