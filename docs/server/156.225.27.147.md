## 吞吐适配（仓库侧）

并发与 heap 已写在：

- `packages/main/pm2.quants.config.cjs`
- `packages/main/.env.quants` / `.env.prod`
- `plugin-stock` / `plugin-quants` `constants.ts`（`envInt` 可读上述 env）

上机更新代码并重建后：

```bash
cd /path/to/packages/main
pm2 start pm2.quants.config.cjs   # 或 delete 旧进程后 start
pm2 save
```

可选：`stocks_settings` 积分档 RPM → 500；MySQL IO 见 [`../服务器配置.md`](../服务器配置.md)「16c 机 MySQL IO / redo」。

## MySQL 契约（升级勿忘）

- **时区 UTC**：`/etc/mysql/mysql.conf.d/99-timezone-utc.cnf` → `default_time_zone = +00:00`（对齐 TypeORM `timezone: 'Z'`）。见 [`../服务器配置.md`](../服务器配置.md)「时区 UTC」。
- **redo**：`/etc/mysql/mysql.conf.d/99-redo-log.cnf` → `innodb_redo_log_capacity = 2G`。见同上「16c 机 MySQL IO / redo」。
