# 内置首页内容规划

更新日期：2026-10-20。状态：内容设计稿，尚未实现页面。

依据：当前工作区的前端页面、路由、公开设置与接口实现。未读取线上配置；文中“系统具备”不等于当前站点已向所有用户开放。

## 1. 首页定位

首页面向第一次访问站点的 AI 工具用户和开发者，回答四个问题：

1. 这里提供什么服务？
2. 可以怎样接入和使用？
3. 去哪里了解模型、费用和使用条件？
4. 下一步应该点击哪里？

定位：**为 AI 工具与应用提供模型 API 接入、密钥管理和用量查询服务。**

内容主线是模型选择、API 接入与使用管理。图像创作属于基于模型服务提供的附加工具，在页面后部简要展示，不进入产品定位、首屏卖点或核心能力清单。

主要目标是引导新用户了解服务、创建账户并完成首次接入；已登录用户可以快速进入控制台。首页不承载账号管理、支付结算和模型调用操作。

设计假设：沿用现有站点品牌、青绿色主色、中英文与明暗主题。站点名和 Logo 读取现有配置；文档中以“本站”代称，不把仓库名或文档中的 AlphaIO 固定为页面品牌。

### 与现有首页的关系

- `builtin_home_enabled` 开启：展示本次规划的内置首页。
- 开关关闭：保持现有“自定义 HTML／URL → 简洁首页 → 默认首页”的选择顺序。
- 自定义首页内容继续保存，开关切换不清空内容。
- “内置”指页面结构、组件和基础文案由前端维护；品牌、入口权限和计费方式仍跟随现有配置。
- 首版不新增首页编辑器、区块配置系统或独立首页接口。

## 2. 内容取舍

| 当前能力 | 首页如何表达 | 展示边界 |
| --- | --- | --- |
| API Key、模型与分组 | 用站点 Key 接入工具或应用 | Key 的可用模型由分组和权限决定，不承诺一个 Key 通用全部模型 |
| 模型广场 | 了解模型、分组和价格 | 受模型广场开关与登录要求控制；首版导向现有页面 |
| 用量记录与仪表盘 | 查看调用、Token 用量和费用 | 展示能力说明，不公开个人账单或运营数据 |
| 充值、订阅、兑换 | 按站点开放方式准备额度 | 仅充值、仅订阅、混合模式的文案分别处理 |
| 图像工作室 | 作为附加工具，简要介绍网页生成和编辑图片 | 使用小卡片展示；需要有图像权限的有效站内 Key，模型和参数以页面实际列表为准 |
| 批量生图 | 有权限用户可使用批量图片任务 | 依赖特定 Key 与分组授权，首版不作为面向所有访客的主卖点 |
| 渠道状态、可用渠道 | 登录后查看渠道信息 | 不把登录后的监控数据搬到公开首页 |
| 工具配置与使用文档 | 提供接入步骤与问题排查 | 展示已有指南入口，不承诺所有客户端版本均可直接兼容 |
| 邀请返利 | 可作为已开放站点的辅助入口 | 首版不占主内容位置，不硬编码返利比例 |
| 管理员功能 | 支撑站点运营 | 用户首页不展示上游账号、代理、调度、风控、插件等管理能力清单 |

## 3. 页面结构

页面按“理解服务 → 了解核心能力 → 了解模型与费用 → 开始接入”的主线组织，随后补充工具入口与常见问题。

| 顺序 | 区块 | 用户得到的信息 | 主要动作 |
| --- | --- | --- | --- |
| 1 | 顶部导航 | 品牌、主要内容入口、登录状态 | 登录／进入控制台 |
| 2 | 首屏介绍 | 一句话定位与核心用途 | 创建账户／进入控制台 |
| 3 | 核心服务能力 | 工具接入、API Key 管理、用量查询 | 查看对应说明 |
| 4 | 模型与费用 | 去哪里选模型、查价格、查看消耗 | 查看模型与价格 |
| 5 | 三步开始使用 | 从账号到首次调用的路径 | 查看接入指南 |
| 6 | 附加工具 | 可选的图像工作室工具入口 | 按需打开工具 |
| 7 | 常见问题 | 模型权限、计费、工具接入、排障 | 查看更多帮助 |
| 8 | 收尾行动与页脚 | 开始入口、支持方式、站点协议 | 注册／控制台／帮助 |

模型广场关闭时，第 4 区块保留符合当前计费模式的说明，移除模型广场按钮；没有可展示的信息时收起整个区块，其他内容自然衔接。

## 4. 各区块内容与文案

### 4.1 顶部导航

左侧展示站点 Logo 和名称；中部保持少量入口：

| 导航名称 | 目标 | 条件 |
| --- | --- | --- |
| 产品能力 | 本页 `#capabilities` | 常驻 |
| 模型与价格 | `/model-plaza` | 模型广场开放；需要登录时先经过登录页 |
| 使用文档 | `/docs` | 常驻 |

右侧放语言切换、明暗主题切换及账户操作。移动端将中部导航收进菜单，保留品牌和账户按钮。图像工作室、渠道监控、返利、订单等不放入首版顶部导航。

### 4.2 首屏介绍

**标识短句**

> AI 模型 API 接入服务

**主标题**

> 为你的工具与应用，接入所需 AI 模型。

**说明文字**

> 按需求选择模型与分组，通过 API Key 接入 AI 工具和应用，在控制台管理密钥、查询调用用量与费用。

**三个能力标签**

- 模型与分组选择
- API Key 管理
- 用量与费用查询

Simple mode 下不显示“用量与费用查询”标签，并从说明文字中移除费用介绍，避免与该模式的计费限制冲突。

**按钮**

- 主按钮按访问状态显示“创建账户”“登录使用”或“进入控制台”，规则见第 5 节。
- 次按钮为“查看接入指南”，前往 `/docs?doc=config-tool`。

**视觉内容**

首屏右侧使用简洁的流程示意：“选择模型与分组 → 创建 API Key → 接入工具或应用”。不放需要执行请求的终端，不嵌入支付窗口。示意卡不填虚构余额、调用量、延迟或运行状态。

### 4.3 核心服务能力

区块标题：**从模型接入，到日常使用管理。**

| 卡片标题 | 正文建议 | 按钮与目标 |
| --- | --- | --- |
| 接入 AI 编程工具 | 按工具要求配置 API 地址、协议和 Key，在现有工作流程中使用可用模型。 | 查看工具配置 → `/docs?doc=config-tool` |
| 为应用接入模型 | 为不同项目创建 API Key，按分组选择可用模型，并在控制台管理使用权限。 | 管理 API Key → `/keys`，未登录先登录 |
| 查看用量与费用 | 在控制台查看调用记录、Token 用量与费用明细，了解项目的实际消耗。 | 查看用量 → `/usage`，未登录先登录 |

Simple mode 下隐藏“查看用量与费用”卡片，其余两张自然排列。

工具名称可以用已有教程中的 Claude Code、Codex、Cursor 作为“接入指南”标签，不标注“全部功能兼容”或“官方合作”。具体安装方式、版本差异和协议配置留在文档中。

### 4.4 模型与费用

区块标题：**先了解模型与费用，再开始使用。**

介绍文字：

> 在模型广场查看分组、模型与价格说明，结合自己的使用需求选择接入方式。登录后可查看账号对应的信息。

当模型广场关闭时，不显示这段文字，改为：

> 登录控制台，查看当前可用分组与站点开放的使用方式。

内容由三个短说明组成：

| 内容 | 文案建议 |
| --- | --- |
| 模型与分组 | 可用模型以当前分组和账号权限为准。 |
| 费用查询 | 在控制台查看调用记录、Token 用量与费用明细。 |
| 获取额度 | 根据站点开放方式，选择充值、订阅或兑换。 |

“获取额度”一句必须根据实际模式改写，不能始终并列三种方式：

| 条件 | 显示文案 | 购买入口 |
| --- | --- | --- |
| 支付开启，充值与订阅均开放 | 充值余额或选择订阅，按自己的使用需求安排额度。 | 充值／订阅 → `/purchase` |
| 支付开启，仅充值 | 充值余额，按实际使用情况查看消耗。 | 账户充值 → `/purchase` |
| 支付开启，仅订阅 | 选择适合的订阅，查看对应分组与使用额度。 | 查看订阅 → `/purchase?tab=subscription` |
| 支付关闭 | 可用额度与开通方式以控制台和站点说明为准。 | 不展示购买按钮；有客服配置时可引导查看联系信息 |
| Simple mode | 不展示充值、订阅、兑换和费用查询内容 | 不展示购买入口 |

首版不在首页复制价格表、套餐卡片或型号清单，不增加模型广场数据请求。主入口使用“查看模型与价格”；购买入口为次级动作。模型广场关闭时可只保留符合条件的购买入口。

后续如增加真实模型卡片，应复用模型广场接口；平台图标只能代表实际返回的模型，不把内置平台目录当作本站在售模型。价格需要完整处理分组倍率、用户倍率、图片独立倍率、时段和上下文档位，不能直接拿参考价作为最终售价。

### 4.5 三步开始使用

区块标题：**从创建账户，到完成第一次使用。**

| 步骤 | 标题 | 正文建议 | 入口 |
| --- | --- | --- | --- |
| 01 | 登录账户，准备额度 | 创建或登录账户，按站点开放方式准备可用额度。 | 注册／登录；已登录进入控制台 |
| 02 | 选择分组，创建 Key | 在 API 密钥页面选择目标模型对应的分组，创建并保存自己的 Key。 | `/keys` |
| 03 | 接入工具，开始使用 | 按指南配置 API 地址、协议、Key 和模型，完成首次调用。 | `/docs?doc=config-tool` |

注册关闭时，第 01 步改为“登录已有账户”，不引导注册。Simple mode 下改为“登录账户”，移除准备额度的描述。

这一区块不承诺“三分钟完成”“注册即送额度”，也不展示真实 Key 或默认可用的模型 ID。

### 4.6 附加工具

区块标题：**按需使用的附加工具。**

放在“三步开始使用”之后，首版仅保留一张紧凑的图像工作室卡片，不为凑齐卡片而添加未确定的工具。

| 工具名称 | 简介 | 入口 |
| --- | --- | --- |
| 图像工作室 | 使用账号下可用的图像模型，在网页中生成、编辑并下载图片。 | 打开工具 → `/image-studio`；未登录显示“登录后使用”，携带回跳地址进入登录页 |

卡片辅助说明：**需有支持图像生成的有效 API Key，具体模型与编辑能力以账号可用列表为准。**

首版采用图标、短说明与文字入口，不设置独立大图、作品画廊或单独的创作引导流程。工具介绍不暗示免费使用、无限生成或云端永久保存；当前历史记录保存在本地浏览器。

文档核对事项：现有图片生成教程仍描述手动配置供应商，当前实现已使用站内 Key 和可用模型列表。工具卡片按当前实现描述，直接导向工作室；正式上线前核对关联教程，本次不修改教程。

### 4.7 常见问题

建议默认展示以下四项，使用折叠列表。

| 问题 | 回答草案 |
| --- | --- |
| 一个 API Key 可以调用所有模型吗？ | 不一定。Key 绑定的分组决定可用模型与权限，请根据目标模型选择对应分组。不同需求可以分别创建 Key。 |
| 如何接入已有工具？ | 在使用文档中找到对应工具，按要求填写 API 地址、协议、Key 和模型。不同工具的配置方式可能不同。 |
| 去哪里了解价格和消耗？ | 模型广场开放时可查看模型与价格说明；登录后可在用量记录中查看自己的调用与费用。实际费用以当前分组、计费规则和使用记录为准。 |
| 请求失败或无法连接怎么办？ | 检查 API 地址、协议、Key、分组和可用额度，再查看文档中的排障说明；仍无法解决时联系站点支持。 |

价格问题在模型广场关闭时移除广场描述，在 Simple mode 下移除整项。最后一项只在配置了联系方式时显示“联系站点支持”。

“更多帮助”指向 `/docs?doc=faq`。无需把长篇配置教程搬入首页。

### 4.8 收尾行动与页脚

收尾标题：**从你的第一个 API Key 开始。**

收尾说明：**登录控制台，选择适合的模型分组，为你的工具与应用创建 API Key。**

主按钮沿用首屏账户状态规则，次入口为使用文档。

页脚包含：

- 站点名称、Logo 与当前年份。
- 使用文档、Key 用量查询 `/key-usage`。
- 已配置且有内容的站点协议，链接到 `/legal/:documentId`，标题取配置值。
- 有 `contact_info` 时显示联系信息；该字段可能是文字，不直接当作 URL。

GitHub 仓库、管理员入口、内部服务信息不作为用户首页的重点。不要编造备案信息、用户评价或合作伙伴标识。

## 5. 状态与入口规则

### 账户主按钮

| 访问状态 | 按钮文字 | 去向 |
| --- | --- | --- |
| 未登录，公开设置已确认允许注册 | 创建账户 | `/register`，旁边提供登录入口 |
| 未登录，注册关闭或配置尚未确认 | 登录使用 | `/login` |
| 普通用户已登录 | 进入控制台 | `/dashboard` |
| 管理员已登录 | 进入管理台 | `/admin/dashboard` |

具体功能按钮跳转受保护页面时，未登录用户经过 `/login?redirect=目标地址`，回跳参数由路由生成，保留目标页面的查询参数。

### 功能入口

| 功能 | 首页展示规则 |
| --- | --- |
| 模型广场 | 通过现有 feature flag 判断；要求登录时，匿名访客按钮写“登录查看模型与价格”，不拉取受限数据 |
| 充值／订阅 | 支付开放且符合当前运行模式时展示；文案由 `resolveSiteBillingMode` 与实际支付配置决定 |
| 图像工作室 | 仅在附加工具卡片提供入口；不因用户尚无 Key 而隐藏卡片，不承诺登录后一定有可用模型 |
| 渠道状态 | 首版不做公开状态卡；后续加入口时须遵守开关、登录要求及现有数据隐藏规则 |
| 可用渠道 | 首版留在控制台；不在匿名首页请求用户渠道列表 |
| 批量生图 | 首版留在控制台；以后如添加入口，必须复用现有 Key 权限检查，不能只检查登录 |
| 邀请返利 | 首版留在控制台；若后续推广，必须依据开关与实际奖励规则展示 |
| Backend mode | 遵守现有路由限制，不为了展示首页放宽后台模式访问权限 |

注册、支付与模型入口不在配置未确认时宣传为已开放。功能开关的默认值复用现有规则；首页不建立另一套判断方式。配置加载失败时仍可阅读基础介绍和文档入口。

## 6. 内容与视觉约定

- 页面以中文内容先行，落地时同步提供英文文案。
- 沿用青绿色与浅灰背景、深色主题，使用留白和层级区分区块。
- 每个区块只讲一个主题，标题一行优先，说明控制在两到三行。
- 顶部与首屏突出一个账户主动作，模型与文档入口作为辅助选择；图像工具入口仅出现在页面后部。
- 桌面端首屏可左右分栏；移动端先文字和按钮，后示意图，卡片改为单列。
- 主要视觉围绕模型接入流程或控制台展开；附加工具采用小卡片，不设置图片创作大屏、工具 Logo 墙或自动轮播。
- 所有本页导航需要真实锚点，并避免被固定导航遮挡；移动菜单选择后关闭。
- 保留键盘操作、清晰焦点、折叠问答的展开状态和减少动画偏好。
- 首页仅提供产品介绍与导航，不展示 Token 刷新、服务端配置注入等实现术语。

### 不使用的宣传表达

不使用缺少实际依据的“全网最低价”“100% 稳定”“永久免费”“无限额度”“官方直连”“零封号”等承诺，也不展示虚构的在线人数、客户数量、成功率、延迟或服务可用率。

需要信任信息时，优先展示可验证的模型价格入口、用量查询、使用文档和支持渠道。

## 7. 首版范围与后续扩展

### 首版

完成第 3 节的页面结构与基础文案，复用站点配置和现有页面入口。首页本身不调用模型、不查询个人 Key、不加载用量或监控数据。

模型与价格采用介绍加入口；图像工作室采用附加工具小卡片，不新增图片素材要求；不新增价格计算器、套餐购买表单、公开状态接口和首页内容管理系统。

### 后续可评估

| 扩展内容 | 启动条件 |
| --- | --- |
| 模型精选与价格预览 | 确定选取方式，并完整复用现有定价展示口径 |
| 附加工具预览 | 有必要说明具体操作，且有经过确认的截图或素材；保持工具卡片层级 |
| 渠道状态摘要 | 已明确可公开的数据范围，有合适的公开接口 |
| 批量生图工具入口 | 确定需要在附加工具中展示，并有清晰的权限说明与开通路径 |
| 邀请活动入口 | 有实际活动规则，且对应功能已开放 |

这些扩展不阻塞首版；本次文档不将其视为已确定的开发范围。

## 8. 落地验收标准

- 首屏明确表达模型 API 接入与使用管理定位，并提供清楚的下一步动作。
- 图像创作仅作为附加工具展示，不出现在定位、首屏标签、核心能力卡片或顶部导航中。
- 内置首页开关开启后展示新页面；关闭后原有自定义内容仍能正常展示。
- 未登录、普通用户、管理员的主按钮文字和目标正确。
- 注册关闭、支付关闭、模型广场关闭时，不出现与配置冲突的宣传和入口。
- 仅充值、仅订阅、混合模式分别显示对应文案；Simple mode 与 Backend mode 沿用当前访问约束。
- 受保护入口登录后回到原目标；首页不提前请求其私有数据。
- 不把平台支持能力、静态示例或参考价误写成当前账号的可用模型与最终售价。
- 图片创作说明与当前站内 Key 流程一致，上线前完成关联教程核对。
- 顶部锚点、页面跳转、FAQ、移动导航可实际操作；无无效按钮。
- 中文、英文及明暗主题正常；窄屏无横向溢出，长站点名不会挤出主按钮。
- 不展示真实 Key、个人账单、上游账号信息或虚构运营指标。
