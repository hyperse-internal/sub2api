## 1. 平台说明

- 不主动将客户输入、输出、代码内容或业务数据用于通用模型训练、微调或蒸馏。
- 不出售、出租、倒卖客户数据。
- 不主动将客户数据用于广告营销、客户画像或对外案例展示。
- 模型标识、费用和调用状态以控制台使用记录为准。
- 保留必要调用日志、费用统计、安全审计和异常核查能力。

## 2. 第三方模型服务

- AlphaIO 当前提供 API Key、支持模型展示、费用统计、调用日志和必要安全审计能力。
- 为完成模型调用，输入内容、调用参数、必要上下文和响应内容可能会传输至平台接入的模型服务商或必要技术合作方。
- 具体可用模型、价格、限流、上下文长度、内容安全策略、可用性、服务区域和数据处理规则，以控制台展示和对应服务商规则为准。
- 第三方模型、云、网络、安全、支付和邮件服务商可能拥有独立服务条款、隐私政策、地区限制、配额限制和数据处理政策；这些规则更新可能影响平台服务。
- 公开页面不会承诺客户自带密钥、固定数据区域、境内专属通道、境外模型默认开关或固定 SLA；如后续上线企业专项能力，应以单独合同、控制台配置和产品说明为准。

## 3. 服务区域与上游可用性

- 本服务并非在所有国家或地区提供；平台可基于访问来源 IP 等对相应地区的访问进行限制，具体受限范围可能随合规要求调整，恕不逐一列明。
- 本站不在公开页面维护固定支持国家或地区清单；实际可用性取决于用户所在地法律法规、支付能力、网络环境、模型服务商和云服务商限制。
- 如某地区、通道、模型或服务商不可用、被限制或存在合规风险，平台可限制、暂停或调整相关访问。
- 用户应自行确认其所在地、业务场景、数据类型和终端用户所在地允许使用相应第三方模型服务。

## 4. 境外模型与数据出境

当您选择境外模型、境外节点或境外服务商时，输入内容、调用参数、必要上下文和响应内容可能被传输至境外或被境外机构访问。

- 调用前请确认数据合法、已授权、已脱敏，并已完成适用的个人信息保护影响评估、数据出境合规评估、认证、标准合同或单独同意等手续。
- 如无法确认数据性质或授权状态，请不要提交至第三方模型服务。

## 6. 日志留存原则

- 默认保存调用元数据，用于计费、审计、费用统计、排障和安全处置。
- 默认不长期保存完整 prompt 或 response。
- 如客户授权排障或安全事件需要访问完整内容，应限定范围、短期处理并留下审计记录。
- 平台可能基于安全、费用、服务稳定性或第三方要求，对请求进行速率限制、额度控制、异常监测和必要拦截。
