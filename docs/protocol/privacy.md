# 隐私政策

更新日期：2026-10-22

本政策说明 AlphaIO（本站）在提供 AI 模型接入网关、API Key 管理、费用统计、调用审计和技术支持时如何处理个人信息、调用数据和必要日志。

核心原则：只处理提供服务所需的数据；默认不长期保存完整输入输出；不主动用于通用模型训练、广告营销、客户画像或对外案例展示。

## 1. 我们处理哪些信息

- **账户信息**：邮箱、登录状态、订阅状态、团队关系和必要通知记录。
- **调用元数据**：request_id、时间、模型、Token、状态码、错误码、费用、延迟和必要安全标记。
- **支付与订单信息**：订单号、金额、支付状态、支付方式、发票和争议处理记录。
- **技术与安全日志**：IP、User-Agent、访问时间、登录事件、异常调用和安全处置记录。
- **API 输入与输出**：仅为完成模型调用、客户授权排障或安全核查在必要范围内短期处理。

## 2. 处理目的

上述信息用于账户认证、提供模型调用、计费结算、费用统计、调用审计、故障排查、安全防护、滥用识别、争议处理以及依法配合监管或司法要求。

## 3. 第三方服务商

为完成服务，必要数据可能传输至模型服务商、云服务商、网络和安全服务商、支付服务商、邮件服务商。第三方会依据其服务条款、隐私政策和数据处理规则处理数据。

如果您使用境外模型、境外节点或境外服务商，可能产生数据出境或被境外机构访问。请先确认数据合法、已授权、已脱敏，并完成适用的数据出境和个人信息保护手续。

## 4. 保存期限

| 数据类型 | 默认策略 | 说明 |
| --- | --- | --- |
| 账户与订单记录 | 按账户存续、财税和争议处理需要保存 | 用于登录、账务、发票、退款、投诉和审计 |
| 调用元数据 | 按计费、安全和审计需要保存 | 包括 request_id、模型、Token、状态、费用等 |
| 完整输入输出 | 默认不长期保存 | 仅在必要调用、客户授权排障或安全核查中短期处理 |
| 安全日志 | 按安全和合规需要保存 | 用于反滥用、异常检测和风险处置 |

- 您可以申请注销账户或撤回同意；依法必须保留的记录除外。
- 您可以就个人信息处理、调用记录或安全事件向我们投诉或咨询。
