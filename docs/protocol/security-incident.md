## 1. 请先采取的措施

- 立即禁用或轮换疑似泄露的 API Key、密码和访问令牌。
- 暂停相关自动化任务或异常调用。
- 保留 request_id、调用时间、订单号、截图、日志、样本和沟通记录。
- 如疑似涉及违法犯罪或国家安全风险，请同时按适用渠道报案或举报。

## 2. 提交核查材料

- 发现时间、涉事账号或团队、API Key 范围。
- request_id 或调用时间段、涉事模型、API Key 或调用路径。
- 异常样本、取证材料、订单号或费用异常截图。
- 是否设置水印、暗标、测试客户、专属联系方式、专属报价编号等来源标记。
- 是否同时向其他平台、供应商、模型服务商、员工、客户或终端用户提供过相同数据。

## 3. 平台核查范围

平台将在合理必要范围内核查可控范围内的调用日志、模型调用记录、访问记录、人工操作记录、异常访问记录和第三方调用记录。

仅凭客户流失、第三方知悉相似信息、网络上出现类似信息或单方怀疑，不能直接认定为平台泄露。泄密认定应以合法、客观、完整、可核验的证据链为基础。

## 4. 投诉举报处理

平台会记录投诉举报内容、处理流程和反馈结果。对违法内容或违法使用，将依法依约采取停止生成、停止传输、限制功能、暂停或终止服务等措施，并保存必要记录。
