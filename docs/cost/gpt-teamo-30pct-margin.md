## 计价规则

| 项 | 说明 |
| --- | --- |
| 成本 | Teamo 现价（站点「缓存」列按 **缓存读取** 理解） |
| 毛利率 | **30%** → 售价 = 成本 ÷ **0.7**（≈ 成本 × 1.4286） |
| 缓存写入（GPT/Claude） | Teamo 未单列；按官方规则估为 **输入成本 × 1.25** |
| 缓存写入（Grok / xAI） | **无独立 cache write**；仅有缓存读取（cached input） |
| 缓存写入（Gemini） | Teamo / 价卡均无独立 cache write；仅「缓存」列按 **缓存读取** |
| 长上下文（Grok） | 价卡阈值 **≥200k**；标准档官价约 **2×** 基础档（Fast 档约 **1.5×**） |
| 计费优先级 | 分组逐模型价 > **渠道模型定价** > 系统价卡，再 × 分组费率倍数 |
| 本方案 | 售价写在渠道；分组费率 1.0；分组逐模型价留空 |

| 字段 | 配置 |
| --- | --- |
| Flex 倍率 | 全部模型 **1**（覆盖系统默认 0.5） |

## 毛利速算

```
售价 = Teamo成本 / (1 - 目标毛利率)
毛利率 30%  →  ÷ 0.7
毛利率 50%  →  ÷ 0.5
```

例：`gpt-5.6-sol` 输入成本 1.07 → 售价 1.07 / 0.7 ≈ **1.53**；`claude-sonnet-5-5` 输入 0.574 → **0.820**；`grok-4.7` 输入 0.23 → **0.329**；`gemini-4-argon` 输入 0.652 → **0.931**。

实际毛利会随 Teamo 调价、Fast/Flex 请求占比、缓存命中率波动；上游涨价未同步改渠道价时，毛利会被侵蚀。
