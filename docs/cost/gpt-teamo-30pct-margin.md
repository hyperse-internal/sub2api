# GPT 成本 / 售价归档（Teamo → 毛利率 30%）

> 归档日期：2026-10-28

> 单位：除非注明，均为 **USD / 百万 tokens**

## 计价规则

| 项 | 说明 |
| --- | --- |
| 成本 | Teamo 现价（站点「缓存」列按 **缓存读取** 理解） |
| 毛利率 | **30%** → 售价 = 成本 ÷ **0.7**（≈ 成本 × 1.4286） |
| 缓存写入成本 | Teamo 未单列；按官方规则估为 **输入成本 × 1.25**（与系统价卡 GPT-5.6 / GPT-6 Sol·Luna·Terra / GPT-6.1 一致） |
| 缓存写入售价 | 缓存写入成本 ÷ 0.7（等价于 **输入售价 × 1.25**） |
| 计费优先级 | 分组逐模型价 > **渠道模型定价** > 系统价卡，再 × 分组费率倍数 |
| 本方案 | 售价写在渠道；分组费率 1.0；分组逐模型价留空 |

### 渠道倍率（生产已生效）

| 字段 | 配置 |
| --- | --- |
| Flex 倍率 | 全部模型 **1**（覆盖系统默认 0.5） |
| Fast 倍率 | 有 Fast 行的模型按「Fast 售价 / 标准售价」写入；其余留空 → 系统默认 **2** |
| Fast / Flex 系统默认 | Fast/priority/ultrafast = **2**；Flex = **0.5** |

## 毛利速算

```
售价 = Teamo成本 / (1 - 目标毛利率)
毛利率 30%  →  ÷ 0.7
毛利率 50%  →  ÷ 0.5
```

例：`gpt-5.6-sol` 输入成本 1.07 → 售价 1.07 / 0.7 ≈ **1.53**。

实际毛利会随 Teamo 调价、Fast/Flex 请求占比、缓存命中率波动；上游涨价未同步改渠道价时，毛利会被侵蚀。
